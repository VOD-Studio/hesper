# 路线图

只把已实现且实际验证的项目标记完成。当前不创建占位机器 crate 或前端。

- [x] **M0：可运行 CPU 最小系统**。两个 Cargo crate；独立 CPU／Bus／RAM；25 个指定 opcode；复位向量启动的原创演示；trace、有限步数、自包含测试；架构、支持清单、验证记录和最小 CI 配置。本地验收完成，结果见 [verification.md](verification.md)；远程 CI 尚未执行。
- [x] **M1：完整 NMOS 官方指令与指令级中断**。151 个官方 opcode／56 条指令及全部官方寻址方式；ADC/SBC 二进制与十进制运算（含 NMOS 特有标志）；BRK/RTI、IRQ/NMI 的指令边界采样、状态压栈、优先级和返回。支持清单逐项对应测试；57 个本地测试在 debug/release 下通过，见 [验证记录](verification.md)。这是按指令模型范围内的完成，不表示逐相位中断兼容或整个外部套件通过。
- [ ] **M2：一致性／总线验证与 Apple I**。在现有 8 条十进制样例之外，按固定版本接入 Klaus Dormann 与 SingleStepTests 的 NMOS 数据；分别报告结果、周期数量与总线序列。交叉参考 Visual6502，演进微操作模型并补齐 dummy access、引脚采样、连续改写 I 的流水线细节、分支末周期延迟及中断重叠／向量抢占验证；随后建立 Apple I 内存映射、文本输入输出与可交互系统。
- [ ] **M3：早期 Apple II**。初始目标为**原版 Apple II**；到此阶段再明确 RAM、ROM 及外设配置。依次实现并验证内存映射、键盘、文本／图形显示、声音及磁盘控制器／介质支持。不得默认混入 IIe、IIc 或 65C02 扩展。ROM 使用与分发方式须先确认来源和权限。
- [ ] **M4：WebAssembly 与浏览器**。建立 Wasm 接入层、浏览器输入输出、运行调度和展示，复用已验证的 CPU／机器实现。CPU 库可编译到 Wasm 仅是构建验证，不等于这个里程碑完成。

跨阶段事项：许可证待所有者确认；非官方 opcode 和芯片修订差异需另行确定范围。外部测试必须固定数据提交、记录许可证及使用方式，不能以部分用例代替完整套件结论，具体原则见 [AGENTS.md](../AGENTS.md)。
