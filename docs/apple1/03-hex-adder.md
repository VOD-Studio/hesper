# 程序 3：两数相加，打印十六进制结果

概念：真正的运算 + 两层子程序调用 + 十六进制数字转 ASCII（nibble → 字符）。这是"计算并显示结果"这一类程序的最小完整样例，也是本文档里字节数最多、结构最复杂的一个。

准备工作见 [`examples.md`](examples.md#2-cli-快速启动)。

## 汇编列表

主程序在 `$0300`，把 `$58` 和 `$27` 相加（结果 `$7F`），打印两位十六进制再换行，然后自旋。`PRHEX` 子程序在 `$0310`，把 A 中的一个字节拆成高/低两个 nibble，各调一次 `PRNIB`。`PRNIB` 子程序在 `$031F`，把 0‑15 的 nibble 转成 `0‑9`/`A‑F` 并通过 `$FFEF` 打印。

| 地址 | 字节 | 指令 | 说明 |
| --- | --- | --- | --- |
| `0300` | `A9 58` | `LDA #$58` | 被加数 |
| `0302` | `18` | `CLC` | |
| `0303` | `69 27` | `ADC #$27` | 加上加数，结果 `$7F` |
| `0305` | `20 10 03` | `JSR $0310` | 调 `PRHEX` 打印结果 |
| `0308` | `A9 0D` | `LDA #$0D` | CR |
| `030A` | `20 EF FF` | `JSR $FFEF` | 打印 CR，换行 |
| `030D` | `4C 0D 03` | `JMP $030D` | 自旋 |
| `0310` | `48` | `PHA` | **PRHEX**：保存整个字节 |
| `0311` | `4A 4A 4A 4A` | `LSR A ×4` | 取出高 nibble |
| `0315` | `20 1F 03` | `JSR $031F` | 打印高 nibble |
| `0318` | `68` | `PLA` | 取回原字节 |
| `0319` | `29 0F` | `AND #$0F` | 取出低 nibble |
| `031B` | `20 1F 03` | `JSR $031F` | 打印低 nibble |
| `031E` | `60` | `RTS` | |
| `031F` | `C9 0A` | `CMP #$0A` | **PRNIB**：nibble 是否 ≥10 |
| `0321` | `90 06` | `BCC $0329` | <10 走十进制数字分支 |
| `0323` | `18` | `CLC` | |
| `0324` | `69 37` | `ADC #$37` | 10‑15 → `'A'`‑`'F'`（`+$37`） |
| `0326` | `4C 2B 03` | `JMP $032B` | 跳过数字分支 |
| `0329` | `69 30` | `ADC #$30` | 0‑9 → `'0'`‑`'9'`（`+$30`），此处进位保证为 0 |
| `032B` | `20 EF FF` | `JSR $FFEF` | 打印这一位字符 |
| `032E` | `60` | `RTS` | |

两条 `ADC` 分支都刻意在前面显式清进位（`CLC`）或依赖 `CMP` 分支保证进位为 0，不依赖"恰好没被上一条指令弄脏"的进位状态。

## 输入步骤

```
300: A9 58 18 69 27 20 10 03
308: A9 0D 20 EF FF 4C 0D 03
310: 48 4A 4A 4A 4A 20 1F 03
318: 68 29 0F 20 1F 03 60 C9
320: 0A 90 06 18 69 37 4C 2B
328: 03 69 30 20 EF FF 60
```

## 运行

```
300R
```

## 实测输出

```
\
…（deposit 命令的回显与例行 examine 输出省略，与前两个程序一致）
300R

0300: A97F
```

`A9` 是 monitor 对当前地址的例行回显（上一次 deposit 的字节），`7F` 才是程序算出并打印的结果——`$58 + $27 = $7F`。另外用 `$F0 + $0F = $FF`（只改第一条 `LDA` 的立即数为 `F0`，`ADC` 改为 `#$0F`）单独测过，确认 `PRNIB` 的字母分支（`A`‑`F`）同样正确：输出为 `FF`。

## 说明

跟程序 1 一样，`$030D` 是死循环自旋，跑完之后 monitor 不会再响应输入，需要重启 CLI（真实硬件按物理 RESET）才能继续用。
