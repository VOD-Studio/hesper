# 程序 2：绕开 monitor，直接读键盘回显

概念：直接轮询 MC6821 PIA（`$D010`/`$D011`），不经过 Woz Monitor 自带的行编辑器。展示的正是 ROM 自己用来读一个键的那套时序：读控制寄存器等第 7 位（`IRQA1`）置位，再读数据寄存器取字符（读数据同时会清掉这个标志位）。

准备工作见 [`examples.md`](examples.md#2-cli-快速启动)。

## 汇编列表

| 地址 | 字节 | 指令 | 说明 |
| --- | --- | --- | --- |
| `0300` | `AD 11 D0` | `LDA $D011` | 读 CRA，第 7 位＝有新键 |
| `0303` | `10 FB` | `BPL $0300` | 第 7 位没置位（N=0）就继续等 |
| `0305` | `AD 10 D0` | `LDA $D010` | 读键值（键盘固定把第 7 位置 1），同时清 `IRQA1` |
| `0308` | `29 7F` | `AND #$7F` | 去掉第 7 位，还原成普通 ASCII |
| `030A` | `20 EF FF` | `JSR $FFEF` | 调用 `ECHO` 打印刚读到的字符 |
| `030D` | `4C 00 03` | `JMP $0300` | 回去等下一个键 |

## 输入步骤

```
300: AD 11 D0 10 FB AD 10 D0
308: 29 7F 20 EF FF 4C 00 03
```

## 运行

```
300R
```

跑起来之后直接打字，每个字符都会被这段代码读到并原样打印出来——和 Woz Monitor 自己的回显效果一样，但完全是我们自己的 16 字节代码做的，不依赖 monitor 的输入缓冲区或命令解析。

## 实测输出

用真实终端敲 `300R` 之后接着敲 `HELLO 6502`：

```
\
300: AD 11 D0 10 FB AD 10 D0

0300: 00
308: 29 7F 20 EF FF 4C 00 03

0308: 00
300R

0300: ADHELLO 6502
```

`HELLO 6502` 是我们这段代码实时回显出来的，逐字符生效，不需要按 Enter。

## 说明：这个程序真的会一直响应

和程序 1/3/4 不同，这里的循环本身就是"读键盘 → 回显 → 再读键盘"，所以它不会陷入"CPU 转但读不到输入"的死状态：只要终端还在跑，输入什么就回显什么。要退出，唯一办法是关掉这个 CLI 进程（`Ctrl+D` 结束 stdin，或直接 `Ctrl+C`）——因为这段代码本身没有回 monitor 的出口。
